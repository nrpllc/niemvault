The flow

Solid edges carry records. Dotted edges carry an identity a hop assigned, which is how the association reaches the two entities it links without re-deriving either. The quarantine path exists on every hop, because a contract is checked on both the way in and the way out.

What each hop does

The two entity hops are independent — a malformed date of birth costs the person, not the incident. The association hop waits for both, because an edge to an entity that was never produced is worse than a missing edge.

When the source drifts

A CAD vendor pushed an update and dates of birth started arriving in ISO format. Every value is still a perfectly valid string, so nothing crashes — which is precisely the failure this platform exists to catch. The contract catches it, the record is quarantined, and the run continues.

The event carries the shape of what arrived, never the value: ####-##-## where ##/##/#### was declared. That is enough to diagnose a format change and safe to put in a log aggregator.

Emitted to the event stream DOB: pattern expected ^\d{2}/\d{2}/\d{4}$ found String(len=10, shape=####-##-##)
Retained in quarantine "NAME_FULL": "OKAFOR, ADA" "DOB": "1979-12-01" "DL_NUM": "R5540021"

Quarantine keeps the real values and lives under bronze's access controls, so the record can be reprocessed once the mapping or the contract is corrected. The event, which travels to dashboards and log aggregators, never holds a date of birth.
